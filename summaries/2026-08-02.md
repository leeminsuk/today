| Memory Decoder at Scale: A Pretrained, Parametric Long-Term Memory | decoder-only LM은 **장기 기억과 추론이 단일 파라미터 집합에 얽혀 있다**는 문제의식에서, 기억을 **별도의 사전학습된 파라메트릭 메모리 모듈**로 분리해 스케일링했다 — 메모리 모듈을 **6.9B 파라미터·300B 토큰**으로 학습했고, 이 규모의 kNN 분포 학습을 위해 분산 Faiss 색인·검색 파이프라인과 배치 단위 희소 로딩을 만들었다. 결과: **6.9B 메모리 + Pythia-410M 조합이 평균 벤치마크 29.86 → 37.34로 Pythia-12B를 초과**하면서 총 파라미터는 39% 적었다. 도메인 특화에서는 1.7B 메모리 모듈이 모든 본체 규모에서 3개 도메인 평균 9점 이상을 더했다. | 어제 Metis가 "메모리를 backbone **안으로**"였다면 이쪽은 "메모리를 backbone **밖으로, 대신 크게**"다 — 같은 주에 정반대 설계가 나란히 나와 **메모리 배치 문제가 열린 설계 공간**임을 보여준다. | PhiZero: A World Model Built Around Physical Language | 세계 모델이 미래를 **픽셀 공간에서 직접 예측하는 대신**, 세계 상태 전이를 담는 **이산적·압축적 "물리 언어(physical language)"**를 중간 표현으로 세웠다. 사람이 시각 경험에서 예측 구조를 추상해 언어로 조직하듯, **비정제(uncurated) 비디오에서 자기지도로 물리 언어를 학습**하고, 미래 전개를 물리 언어 시퀀스로 추론한 뒤(reason) 그것을 비디오로 렌더링한다(render). 여러 벤치마크에서 물리적으로 정합적인 세계 변화 모델링을 검증했고, 상호작용형 세계 모델링·세밀한 행동 조건 시뮬레이션·**zero-shot 모션 전이**를 시연했다. | 07-30 브리핑의 HF Daily Papers에서 본 VideoCoCo(Blender 코드를 CoT로 쓰는 물리 정합 비디오)와 같은 계열 — **"물리를 픽셀에서 추론하지 말고 명시적 중간 표현에서 추론하라"**는 reason-then-render 패러다임이 한 주 사이 두 번째다. 차이는 중간 표현의 출처다: VideoCoCo는 사람이 만든 형식 언어(Blender 코드)를 빌렸고 PhiZero는 **표현 자체를 자기지도로 학습**했다 — 후자가 일반성에서 앞서지만, 학습된 이산 표현이 실제로 "물리"를 담는지 아니면 시각 패턴의 압축인지는 벤치마크 구성을 봐야 판별된다(abstract에는 정량 수치가 없다). 로보틱스 관점에서는 어제 Gemini Robotics 2의 ER 2(판단)-VLA(실행) 분리와 동형의 구조가 세계 모델 안에서 반복되고 있다는 점을 기록한다 — **추론과 렌더링/실행의 분리가 이번 주의 지배적 설계 패턴**이다. | [arXiv](https://arxiv.org/abs/2607.28624) |
